받음 대기 중
다른 담당자의 그리기 코드에서 연결하기 
const glyphs = [
  { character: "A", canvas: canvasA, baseline: 320 },
  { character: "a", imageData: imageDataA, baseline: 320 }
];

// 1. 여러 글자를 변환 화면에 등록
HANDDIMIFont.registerGlyphs(glyphs, { replace: true });

// 2. 등록된 글자를 OTF 데이터로 변환
const result = HANDDIMIFont.convertToOtf({
  familyName: "HANDDIMI"
});

// 실제 OTF 바이너리 데이터
const otfArrayBuffer = result.buffer;

Canvas, p5 Renderer, ImageData, 또는 strokes 배열을 받을 수 있습니다. ES module에서는 registerGlyphs와 convertToOtf를 직접 import할 수도 있습니다.
